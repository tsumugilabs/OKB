# OKB（仮タイトル）— 護衛スナイパー

前作『Elevator Action（ブラウザ版）』の**狙撃演出「OKB」**を土台に、
**護衛対象を狙撃で守り抜く**ストーリー型シューティングに作り替えたブラウザゲーム。
素の JavaScript + HTML5 Canvas、ビルド不要で `index.html` を開くだけで遊べます。

- 参照元エンジン: [`tsumugilabs/elevator-action`](https://github.com/tsumugilabs/elevator-action)
  （`docs/HANDOFF.md` とエンジン `audio/input/entities/level/game` を土台に着せ替え）

## コンセプト

- **ジャンル**：ストーリー型・護衛スナイパー。
- **役割**：プレイヤーは**屋上のスナイパー**。地上を歩くキャラは操作しない。
- **護衛対象＝前作の主人公**：潜入エージェントが**自律的に**出口へ歩く。
  これを妨害しに現れる敵を、プレイヤーが**タップ狙撃**して排除し、守り抜く。
- **横スクロール**：護衛ステージはカメラが護衛対象を追い、1画面より長いルートを進む。
- **狙撃演出**：残しつつ、OKB 13 の劇画「有罪（ギルティ）」カットは**基本省略**
  （通常キルは時間を止めない即キル＋リロード）。**首魁と裏切り者を撃つ時だけ**
  ギルティ演出を発動する“決着”として温存。
- **裏切りの終章**：護衛対象が寝返り、**元・護衛対象を排除する**狩り（hunt）モード。
  一定速度では単調なので、標的は**物陰から物陰へ隠れて逃走**し、**露出した隙**を突く。
- **ストーリーテリング**：ステージ前後に**忍者龍剣伝ライク**の劇中劇
  （全画面グラフィック＋台詞ボックスのタイプライター送り）。
- **物語**：スナイパー “OKB” が、機密を持つ「エージェント」を組織〈カゲロウ〉の
  刺客から守り抜く…はずが、終章で裏切られる。全4章のオリジナル・スパイノワール（既存 IP 不使用）。

## 遊び方

護衛対象（青いトレンチコートの男）は**勝手に右の EXIT へ歩きます**。
敵は**遠く＝小さく**見えており、そのままでは撃てません。**ダブルクリック
（タッチはピンチイン）でスコープを覗く**と、照準点を中心に**拡大**され、カメラが
固定されます。照準は**ドラッグ／マウス移動**で合わせ、**専用の SHOT ボタン
（Space / F）で発砲**します（画面タップでは撃たないので狙点がズレません）。

**リロードは手動**：1発撃つと薬室は空になり、**RELOAD ボタン（R）**で再装填します。
RELOAD は押すと**強制的に素の視界へ戻る**ので、「構える→撃つ→下ろして込める」の
狙撃のリズムが生まれます。

- **敵に撃たれる／接触される**と護衛対象の**HPが減少**。HP 0 で**護衛失敗**。
- 護衛対象が **EXIT に到達すれば護衛成功**。
- ⚠ **誤射（護衛対象を撃つ）に注意**：1回ごとに護衛対象が**遅くなり**、**敵の出現も増える**。
  **3回で護衛失敗**。

### 誤射の“ツケ”と持ち越し（終章の伏線）

終章の裏切り者は**超高速**で、通常は**3ヒットしないと倒せない**（1発当てるのがやっと）。
だが ―― 護衛対象と裏切り者は**同一人物**。前章までに**誤射して負わせた傷が持ち越され**、
終章の標的の**HPと移動速度がその分削られる**。誤射は3回で失敗なので、持ち越せる負傷は
最大2＝終章HPは 3→1。**あえて傷を負わせる**というリスク＆リワードが最終戦の攻略になる。

### 操作

| 操作 | 動作 |
| --- | --- |
| **ダブルクリック / ピンチイン** | **スコープON**（拡大・カメラ固定） |
| マウス移動 / タッチドラッグ | 照準（スコープ内で敵に合うと赤く点灯） |
| **SHOT ボタン** / `Space` / `F` | **発砲**（スコープ中・装填済みのみ） |
| **RELOAD ボタン** / `R` | **再装填**（＝スコープ解除・手動） |
| ピンチアウト / 再ダブルクリック | スコープ解除 |
| `Enter` / `Z` / タップ | 劇中劇を進める |
| `M`（右上の🔊） | サウンド ON/OFF |

> 🔭 **スコープ狙撃**：素の視界では敵は遠く小さく、狙撃できるのはスコープを覗いた
> 拡大表示の中だけ。**トリガーは照準と分離**（画面タップでは撃たない）＝狙点がズレない。
> **1発撃つと薬室は空**になり、RELOAD（スコープを下ろして再装填）が必要 ―― 
> 「構える／撃つ／込める」の間合いが狙撃らしさを生みます。

### 敵の種類

- 🟥 **ガンナー**：定点から護衛対象を狙撃。**近づくと起動**し頭上に「!」の予兆。**発砲前に撃て**。
- 🟥 **ラッシャー**：護衛対象へ突進。**接触される前に撃て**。
- 🟧 **首魁〈鴉〉（第三章ボス）**：撃つと**ギルティ演出**が発動する特別な標的。
- 🟥 **裏切り者（終章）**：物陰を渡って逃走。**覗き見／ダッシュの露出**を捉えて狙撃（決着でギルティ）。

## 起動方法

```bash
# ローカルサーバー経由（推奨）
python3 -m http.server 8000
# → ブラウザで http://localhost:8000 を開く
# もしくは index.html を直接開く
```

## 単一HTMLビルド（配布・Artifact用）

外部依存ゼロの**自己完結HTML**を生成できます（そのまま開けば遊べる／Artifact公開可）。

- **本編（全4章）**： `node tools/build-single.js`
  → `okb.html`（スタンドアロン）と `okb.artifact.html`（Artifact本文フラグメント）を生成。
- **テストプレイ用・単一ステージ**： `node tools/build-teststage.js`
  → `teststage.html` と `teststage.artifact.html`（コンテナヤード＋ボス演出の1ステージ）。

## ステージ構成（本編・全4章）

第1〜3章は**横スクロール**の護衛ステージ（カメラが護衛対象を追う）。終章は
**裏切りの狩り**―― 護衛対象が寝返り、**元・護衛対象を排除する**新モード。

| 章 | 舞台 | モード | 内容 |
| --- | --- | --- | --- |
| 第一章 | 港 | 護衛（横スクロール） | ガンナー中心。リロードの練習 |
| 第二章 | 歓楽街 | 護衛（横スクロール） | ガンナー＋突進ラッシャー |
| 第三章 | 塔上 | 護衛（横スクロール） | 密度アップ＋首魁〈鴉〉（GUILTY） |
| 終章 | 屋上 | **狩り（hunt）** | 裏切り者が物陰を渡って逃走。露出した隙を狙撃（決着でGUILTY） |

- **ガンナー**は護衛対象が**近づくと起動**（頭上「!」が予兆）。定点に配置される。
- **狩り（hunt）**：標的は「物陰→覗き見→ダッシュ」を繰り返して EScAPE へ。
  **覗き見／ダッシュ中の露出**を捉えて撃つ。逃がすと失敗。
- テンポは `game.js` の `COOLDOWN_MAX`（リロード）、難度は各章の
  `escortSpeed / escortHp / spawns` と敵の `range`（起動距離、`entities.js`）、
  狩りの `HIDE_T / PEEK_T / DASH_SPEED`（`entities.js`）で調整できます。

## 構成

```
OKB/
├── index.html         # エントリ（HUD・オーバーレイ・<script>読み込み順）
├── css/style.css      # スタイル（オーバーレイ / 結果画面）
├── js/
│   ├── audio.js       # Web Audio 合成SFX・BGM（前作から移植・再スコア）
│   ├── input.js       # ポインタ照準＋タップ射撃＋キーボード
│   ├── entities.js    # Escort（自律歩行・HP）＋ Enemy（gunner/rusher）＋ AABB
│   ├── scene.js       # 護衛ルート＝背景＋出口＋敵スポーン表（level.js の置換）
│   ├── cutscene.js    # 忍者龍剣伝ライク劇中劇（背景＋立ち絵＋台詞ボックス）
│   ├── story.js       # 章立ての台本データ
│   └── game.js        # メインループ / 状態機械 / 護衛ループ / 狙撃 / ボス演出
└── docs/
    ├── HANDOFF.md     # 引き継ぎメモ（前作から継承・更新）
    └── DESIGN.md      # 構成案（設計方針・再利用/置換のマッピング）
```

読み込み順は **audio → input → entities → scene → cutscene → story → game**（依存順）。

## 前作からの再利用と置換

| 前作（elevator-action） | OKB での扱い |
| --- | --- |
| 状態機械 + `tick()` ループ | 再利用（`MENU/CUTSCENE/PLAY/RESULT/OVER/ENDING`） |

| 入力抽象 `Input` | 改修（ポインタ照準＋タップ射撃） |
| AABB `overlaps`/`pointIn` | 再利用（敵のタップ判定） |
| OKB 13 狙撃演出・GUILTY カット | **ボス限定の演出に温存**（`drawGuiltyCut` 移植） |
| `level.js`（ビル・エレベーター） | **置換** → `scene.js`（護衛ルート＋スポーン表） |
| 平面アクション（プレイヤー操作） | 廃止（護衛対象が自律歩行） |

詳細は [`docs/DESIGN.md`](docs/DESIGN.md) を参照。
