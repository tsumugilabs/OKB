# OKB（仮タイトル）— ストーリー型スナイパー

前作『Elevator Action（ブラウザ版）』の**狙撃演出「OKB」**（ズーム→ロックオン→
劇画調「有罪（ギルティ）」カット→ヘッドショット）を、そのまま**主役の遊び**に
据えた、素の JavaScript + HTML5 Canvas によるブラウザゲームです。ビルド不要で、
`index.html` を開くだけで遊べます。

- 参照元エンジン: [`tsumugilabs/elevator-action`](https://github.com/tsumugilabs/elevator-action)
  （`docs/HANDOFF.md` とエンジン `audio/input/entities/level/game` を土台に着せ替え）

## コンセプト

- **ジャンル**：ストーリー型スナイパーシューティング。
- **骨格**：前作の平面アクション（ビル探索）は捨て、**1画面のシーンに現れる標的を
  狙撃する**骨格に差し替え。前作では“おまけ武器”だった狙撃を**唯一の動詞**にした。
- **物語**：孤高のスナイパー “OKB” が「有罪」の契約だけを遂行する、
  オリジナルのスパイ・ノワール（全3章）。既存 IP は不使用。

## 遊び方

スナイパー “OKB” として、シーンに現れる**赤い腕章の標的だけ**を狙撃します。
市民や護衛を撃つ（誤射）、標的を取り逃がす、時間切れ ―― いずれもカバーを失い、
0 でミッション失敗。全標的を排除するとミッションクリアです。

### 操作

| 操作 | 動作 |
| --- | --- |
| マウス移動 / タッチ移動 | 照準を合わせる（標的上で赤く点灯） |
| クリック / タップ | 射撃（標的なら狙撃演出が発動） |
| `Enter` / `Space` / `Z` | ストーリーを進める |
| `M`（または右上の🔊） | サウンド ON/OFF |

- **標的（撃つ）**：赤い腕章・赤いハットバンド、足元に赤いリング。
- **市民・護衛（撃つな）**：それ以外の歩行者。誤射でカバー −1。
- **狙撃演出**：標的をタップすると時間が止まり、ズーム→ロックオン→
  劇画「有罪（ギルティ）」カット→ヘッドショット→余韻、が入ります。

### ステージ（全3章）

| 章 | シーン | 標的数 | 特徴 |
| --- | --- | --- | --- |
| 第一章 | 港の受け渡し | 1 | チュートリアル。標的はゆっくり |
| 第二章 | 夜の歓楽街 | 3 | 人波が多く標的も足早。誤射に注意 |
| 終章 | 塔上の首魁 | 1 | 護衛（撃つな）が周囲を固める中の一撃 |

## 起動方法

追加の依存やビルドはありません。

```bash
# 方法1: ファイルを直接開く
open index.html            # macOS
xdg-open index.html        # Linux

# 方法2: ローカルサーバー経由（推奨）
python3 -m http.server 8000
# → ブラウザで http://localhost:8000 を開く
```

## 構成

```
OKB/
├── index.html         # エントリ（HUD・オーバーレイ・<script>読み込み順）
├── css/style.css      # スタイル（オーバーレイ / ストーリー / 結果画面）
├── js/
│   ├── audio.js       # Web Audio 合成SFX・BGM（前作から移植・再スコア）
│   ├── input.js       # ポインタ照準＋キーボード（狙撃はタップ）
│   ├── entities.js    # 標的アクター Mark と AABB ヒットテスト
│   ├── scene.js       # ミッションのシーン背景＋標的スポーン表（level.js の置換）
│   ├── story.js       # 章立てストーリーデータ
│   └── game.js        # メインループ / 状態機械 / 狙撃コア / GUILTY演出
└── docs/
    ├── HANDOFF.md     # 引き継ぎメモ（前作から継承・更新）
    └── DESIGN.md      # 構成案（設計方針・再利用/置換のマッピング）
```

`index.html` の読み込み順は **audio → input → entities → scene → story → game**（依存順）。

## 前作からの再利用と置換

| 前作（elevator-action） | OKB での扱い |
| --- | --- |
| 状態機械 + `tick()` ループ | **再利用**（`MENU/STORY/PLAY/RESULT/OVER/ENDING`） |
| 合成オーディオ `Sound` | **再利用**（曲を D-minor のスパイ調に再スコア） |
| 入力抽象 `Input` | **改修**（十字キー→ポインタ照準＋タップ射撃） |
| AABB `overlaps` | **再利用**（標的のタップ判定に転用） |
| OKB 13 狙撃演出・GUILTY カット | **主役に昇格**（`drawGuiltyCut` 一式を移植） |
| `level.js`（ビル構造・物理） | **置換**（`scene.js`：シーン背景＋スポーン表） |
| 平面アクション（移動・重力・エレベーター） | **廃止** |

詳細な設計方針は [`docs/DESIGN.md`](docs/DESIGN.md) を参照。
