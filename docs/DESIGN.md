# OKB 構成案（設計方針）

前作 `tsumugilabs/elevator-action` の `docs/HANDOFF.md` とエンジンを土台に、
**狙撃要素を主役にした別ゲーム**として OKB を立ち上げるための設計メモ。
本ドキュメントは「何を再利用し、何を差し替えたか」と「今後の伸びしろ」を示す。

## 1. コンセプト確定

| 項目 | 内容 |
| --- | --- |
| 仮タイトル | **OKB** |
| ジャンル | ストーリー型スナイパーシューティング |
| 主役の動詞 | **タップで狙撃**（前作 OKB 13 の演出＝ズーム→ロック→有罪カット→ヘッドショット） |
| 骨格 | 前作の平面アクションを捨て、**1画面シーンの標的狙撃**に差し替え |
| 物語 | 孤高のスナイパー “OKB”／全3章のオリジナル・スパイノワール（既存IP不使用） |
| 技術 | 素の JS + HTML5 Canvas、ビルド不要、Web Audio 合成音、モバイル対応 |

**設計の核心**：前作で“おまけ特殊武器”だった OKB 13 の狙撃演出は、本作で最も
手触りの良い部分。これを**ゲーム全体の中心ループ**に昇格させ、周囲を物語と
「撃つ／撃たない」の判断ゲームで固める。

## 2. 中心ループ

```
STORY(章の導入) → PLAY(狙撃) → [標的をタップ→GUILTY演出→ヘッドショット] × 標的数
              → RESULT(命中率・ボーナス) → STORY(章の締め) → 次章 … → ENDING
```

- **PLAY**：シーンに歩行者（`Mark`）が時間表に沿って出現。**赤い標的**を撃ち、
  **市民・護衛**は撃たない。
- **失敗条件**：誤射／標的の逃亡／時間切れ → カバー減、0 で `MISSION FAILED`。
- **クリア条件**：シーンの全標的を排除。

## 3. 状態機械（前作の `tick()` を踏襲）

```
STATE = { MENU, STORY, PLAY, RESULT, OVER, ENDING }
game.snipe        // 狙撃演出中は PLAY の時間を凍結（前作 OKB 13 と同じ作法）
```

1本の `tick()`＝`update()`＋`draw()`＋`Input.endFrame()`。演出中は世界を止める、
という前作の勘どころをそのまま流用している。

## 5. データ駆動の拡張点

- **シーン**（`scene.js` の `SCENES`）：`{ name, ground, timeLimit, drawBg, spawns[] }`。
  `spawns` は `{ t(出現フレーム), dir, speed, type("target"|"civ"), palette? }`。
  → 面追加＝オブジェクトを足すだけ。背景はベクター描画関数を差し替え。
- **ストーリー**（`story.js`）：`prologue / chapters[{brief, scene, outro}] / ending`。
  → 章追加＝配列に足すだけ。`scene` キーで `scene.js` と紐づく。
- **難易度カーブ**：前作の「周・面で難易度を返す純関数」の思想を踏襲し、将来
  `speed / spawn密度 / 制限時間 / 弾数` をパラメータ化予定。

## 6. 判断ゲームの伸びしろ（今後）

前作の狙撃は「動いていれば当たらない」布石だった。本作はその逆で
「**誰を撃つか**」を核にする。以下を段階的に追加予定：

- **識別ギミック**：変装・入れ替わり・人質を取る標的・偽の腕章。
- **制約**：弾数制限、風・距離による偏差、リロード、移動標的の先読み。
- **演出強化**：命中率ランク、連続キルの評価、章末リザルト。

## 7. デプロイ運用（前作 HANDOFF を踏襲）

1. `node --check js/*.js` で全 JS 構文チェック。
2. Playwright（headless Chromium）＋ `python3 -m http.server` で表示確認。
3. 単一HTML（Artifact）化：CSS/JS を読み込み順にインライン（CSP 対策・画像は data URI）。
   現状の GUILTY 演出は**画像不使用の純ベクター**なので埋め込み不要。
4. Git：開発ブランチ → PR。GitHub Pages（deploy from branch、`.nojekyll` あり）。

## 8. 作法（IP/著作権）

- 出自不明の既製画像は公開物に埋め込まない。キャラ・背景・演出は**自前ベクター**か
  ドット絵で用意する（前作の方針を継承）。
- 物語・固有名詞（〈カゲロウ〉〈鴉〉等）は本作のオリジナル。
